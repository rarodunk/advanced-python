# v4: the guide on real imagery

`index.html` is generated by `python3 v4/tools/build.py` from the v2 shell and
data, `map.js` (north-up Web Mercator viewport; pins placed by latitude and
longitude, no island model in between) and `../imagery.jpg` + `../imagery.json`.

The committed `imagery.jpg` is a synthetic stand-in drawn from the island model
by `standin.js`, so the page can be built and tested offline. Replace it with
satellite imagery by running, on a machine with internet access:

    pip install pillow
    python3 tools/fetch_imagery.py        # Esri World Imagery, zoom 16
    python3 v4/tools/build.py

`imagery.json` carries the mosaic's exact bounding box, which is all the page
needs to place every pin on the right building. Open the page with `?fit=1` to
see the model coastline and four reference crosses (airport, Te Manga, Muri,
Black Rock) drawn over the base as a sanity check.

For the App Store build, use Apple MapKit's satellite layer instead of a baked
mosaic: it is free to iOS apps, matches the phone's own Maps, and zooms to
street level. The pin placement code is the same, it only needs the map's
coordinate conversion instead of `llToImg`.
